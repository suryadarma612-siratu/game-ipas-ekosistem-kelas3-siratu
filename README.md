# 🧭 Petualangan Penjelajah Ekosistem

Game edukasi 2D IPAS kelas 3 SD (HTML5 Canvas, satu file `index.html`, tanpa instalasi).
Bisa dimainkan di HP Android, iPhone, tablet, laptop, dan komputer.

## Fitur
- Login nama siswa dan kelas, progres tersimpan di perangkat
- 10 level ekosistem, 50 kartu koleksi, kuis, lencana, Laboratorium Ekosistem
- Peringkat skor di beranda
- Menu Petunjuk Bermain

## Menjalankan
Buka `index.html` di peramban, atau aktifkan GitHub Pages:
**Settings → Pages → Source: GitHub Actions**. Setiap `git push` ke `main` akan otomatis terbit di
`https://USERNAME.github.io/NAMA-REPO/`.

## Catatan peringkat
Di GitHub Pages, peringkat disimpan di perangkat masing-masing (localStorage).
Peringkat bersama lintas perangkat butuh backend (misalnya Firebase atau Supabase).
